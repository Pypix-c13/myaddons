# SurviveTheFoid Addons
- Addons for survive the void world
- a simple addons for beginner

## Command
- `/io:score`
- `/io:basic`
- `/io:farm <wood|stone>`
- `/io:reward`

## GUI
- coordinat, days and time at the same straight line

## Feature
- starterpack => cost 1 death to give wooden sword, axe and pickaxe, 16 bread and 8 oak log
- big farm    => cost 64 death to make big wood farm or coblestone farm
- reward      => cost 32 death to give player 10 obsidian and 1 flint and steel
- time        => show real time clock
